# SoulBound

SoulBound is a 2D top-down mobile RPG developed using Godot Engine on a mobile device.

## Download
You can download the Android APK from itch.io:
https://strowy.itch.io/soulbound

## Project Overview
- Engine: Godot Engine
- Programming Language: GDScript
- Platform: Android
- Features: Custom movement controller, enemy state machine, context steering pathfinding, JSON save system, and shader effects.
